# Synthetic bibliography exchange fixtures (#13)

`generate_exchange.py` deterministically writes **1,000 actual source records per format**:
`bibtex/thousand.bib` (707,906 bytes) and `ris/thousand.ris` (591,331 bytes). They are authored
with original-format templates, not generated by the production serializers. No literature,
PDFs or personal library data are included. `example.invalid` URLs and `10.9999` DOI strings
are synthetic. Hash-based titles make unrelated rows distinct under #33's fuzzy matching;
this is a fidelity/correctness fixture, not a representative performance benchmark.

Both cover seven type families, four ordered contributors including a corporate/literal
name and editor, Unicode/escaped punctuation, DOI/URL/year/date/journal/volume/issue/pages/
abstract/language/keywords/accessed date/citation key, and unknown publisher/custom fields.
RIS also includes folded multiline abstracts, repeated keywords and SP/EP pairs. Malformed,
encoding, macro, collision, merge/skip/cancel, extension and budget cases are inline fixtures
in `crates/daemon/tests/bibliography_behavior.rs`.

SHA-256:

- BibTeX: `d767de29467d7ebb76ba49284b721afbee31f46ed08827de03952325a115fc91`
- RIS: `89315f93948eebb687a3dbc02ab1f9d75f019f00b0442557f6fa43c71bfe1f88`

Run `python3 fixtures/generate_exchange.py` to reproduce. DB round-trip checks are in
`crates/daemon/tests/bibliography_roundtrip.rs`; the daemon composition layer is the allowed
place to connect real metadata adapters to real storage. See
[the ADR](../docs/ADR/bibliography-exchange.md) for limits and extension fidelity.
